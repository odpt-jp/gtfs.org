# 概要 {: #about}


GTFS.org は、General Transit Feed Specification の中心的なドキュメントプラットフォームです。このサイトおよびそのコンテンツは、[MobilityData](https://mobilitydata.org/) によって維持管理されています。

GTFS.org ドメイン名を購入し、その使用を貸与するとともに、コミュニティにリーダーシップを提供してくださった [Andrew Byrd](https://www.linkedin.com/in/byrdandrew) に感謝いたします。

## GTFS.org への貢献 {: #contributing-to-gtfsorg}


このウェブサイトのコンテンツに対する編集を提案するには、[documentation@mobilitydata.org](mailto:documentation@mobilitydata.org) から MobilityData にお問い合わせいただくか、[GTFS.org GitHub Repository](https://github.com/mobilitydata/gtfs.org) にアクセスして、プルリクエストとして編集内容を提出してください。

翻訳については、GTFS.org は翻訳がリポジトリの変更に合わせて最新の状態に保たれるよう、自動化ツールを使用しています。翻訳を最新の状態に保つことを優先しているため、どの言語であっても手動で修正された翻訳は、最終的に上書きされることにご注意ください。

trip や station のように、GTFS.org 全体で一般的に使用される主要な用語については、用語集の変更を受け付けています。サイト全体に適用されるべき主要な用語の翻訳を提案したい場合は、[GTFS.org GitHub Repository](https://github.com/mobilitydata/gtfs.org) で issue を作成することができます。

## GTFS の進化 {: #gtfs-evolution}


GTFS は、オレゴン州ポートランドの TriMet と Google の協力により始まりました。TriMet は Google と協力し、自社の公共交通データを、Google Maps にインポートできる、容易に保守および利用できる形式に整えました。この公共交通データ形式は、当初 Google Transit Feed Specification (GTFS) として知られていました。

開発者による革新の結果、GTFS データは現在、旅程計画、時刻表作成、モバイルデータ、データ可視化、アクセシビリティ、および計画のための分析ツールなど、多くの異なる目的で、さまざまなサードパーティ製ソフトウェアアプリケーションにより使用されています。 

2010 年には、Google 製品以外の多くの異なるアプリケーションでの利用を正確に表すため、GTFS 形式の名称が General Transit Feed Specification に変更されました。2011 年には GTFS Realtime の作成によりリアルタイム情報機能が仕様に追加され、2019 年には、コミュニティの支援を受けて GTFS をさらに維持するため、非営利団体 [MobilityData](https://mobilitydata.org/) が設立されました。

公共交通データ形式の中で、GTFS は、運用上の詳細を管理するための網羅的な語彙としてではなく、乗客にサービス情報を伝達するという具体的かつ実用的なニーズを満たすために考案された点で際立っています。これは、人間と機械の双方にとって、比較的簡単に作成および読み取りできるよう設計されています。 

GTFS の起源に関するさらなる背景については、[Pioneering Open Data Standards: The GTFS Story](https://beyondtransparency.org/chapters/part-2/pioneering-open-data-standards-the-gtfs-story/) および [How Google and Portland’s TriMet Set the Standard for Open Transit Data in Streetsblog SF](https://sf.streetsblog.org/2010/01/05/how-google-and-portlands-trimet-set-the-standard-for-open-transit-data) を参照してください。
