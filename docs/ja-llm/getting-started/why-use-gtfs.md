# より多くの乗客にリーチし、GTFSで公共交通を改善する {: #reach-more-riders-and-improve-public-transit-with-gtfs}

GTFSは現代の交通システムの基盤として機能し、事業者が乗客、アプリ開発者、政策立案者に正確かつ最新の情報を提供できるようにします。以下では、GTFSのさまざまな利点と、それが世界中の公共交通をどのように向上させるかを説明します。

## 広く利用され、世界的に採用されています {: #widely-used-globally-adopted}


100か国以上の10,000を超える事業者がGTFSを利用しており、複数事業者にまたがる便における一貫したデータを確保し、地域をまたぐ移動を簡素化しています。GTFSが世界的な到達範囲とシームレスな移動をどのように実現するかを以下に示します。

- **標準化されたデータ:** GTFSは交通データの標準化された形式を提供し、事業者および地域間での一貫性を確保することで、乗客の移動計画を簡素化します。
- **複数事業者にまたがる便:** GTFSにより、事業者は一貫性があり信頼できるデータを共有でき、複数の交通システムをまたいで移動する乗客にシームレスな移動体験を提供できます。

## コミュニティ主導の開発と自由なアクセス {: #community-driven-development-and-freely-accessible}


GTFSはコミュニティの協働によって発展しており、仕様においては乗客向け情報を主な焦点として、継続的な進化と関連性を確保しています。

- **オープンな協働:** GTFSはオープンデータ標準として運用されており、誰でも変更や改善に貢献することができます。
- **指針に基づく進化:** 仕様の進化は、[MobilityData](https://mobilitydata.org/)という独立した非営利組織によって監督されており、その変更は使いやすさ、後方互換性、および実用的な変更の原則に基づいて行われます。 
- **コミュニティ主導の開発:** GTFS仕様は、[GitHub](https://github.com/google/transit)や[Slack](https://share.mobilitydata.org/slack)などのプラットフォームで促進される、コミュニティからの意見およびレビューを通じて継続的に改善されています。

## シンプルで使いやすい {: #simple-and-easy-to-use}


GTFS は、容易なデータ交換を可能にし、より円滑なサービス統合と情報共有を促進することで、交通事業者間の連携を促します。GTFS がデータ共有を簡素化する方法は次のとおりです。

- **統合の容易さ:** GTFS は、.txt や GeoJSON などの一般的なファイル形式を使用したシンプルなデータ構造により、事業者が容易に利用を開始できるようにし、連携と相互運用性を促進します。
- **後方互換性:** 仕様を更新する際、既存のフィードは有効なままであり、既存のパーサーとの互換性を維持します。

## GTFS はおそらく、あなたが考えている以上のことができます {: #gtfs-can-probably-do-more-than-you-think}


GTFS の中核はスケジュール情報ですが、次のように、交通機関の利用体験を向上させる追加機能も提供しています。

- **運賃:** GTFS には、ルート・路線系統(route)および旅程(journey)の選択肢ごとに正確な費用内訳を提供するための運賃情報を含めることができます。
- **柔軟なサービス:** GTFS は、予約型乗合サービス、ルート逸脱、およびスケジュール化されたサービスや固定サービスの一般的な挙動に従わないその他のサービスなど、デマンド型サービスの選択肢を記述できます。
- **構内通路(pathway):** GTFS は大規模な交通駅をモデル化でき、乗客が駅の出入口から交通車両に乗車または降車する場所まで移動するのを支援します。

## 乗客体験の向上 {: #improved-rider-experience}


GTFS が乗客を支援し、その体験を向上させる方法は以下のとおりです。

- **最新情報:** GTFS は、時刻表、ルート・路線系統(route)、および停留所等(stop)の情報へのアクセスを乗客に提供し、十分な情報に基づく移動の意思決定を促進します。
- **待ち時間の短縮:** GTFS Realtime は車両位置情報(vehicle position)に関するライブ更新を提供し、待ち時間を短縮するとともに、全体的な移動体験を向上させます。

## 幅広いアプリケーションへのアクセス {: #access-to-a-wide-range-of-applications}


GTFSを採用することで、事業者は標準化されたデータ形式を利用する膨大なアプリ開発者の層を通じて、より幅広い利用者にリーチできます。GTFSがアプリやサービスの利用者基盤をどのように拡大するかを以下に示します。

- **アプリのリーチ拡大:** GTFSデータへのアクセスにより、アプリ開発者はより幅広い公共交通の乗客にリーチでき、公共交通アプリの使いやすさと機能性が向上します。
- **相互運用性:** オープン標準は、交通事業者とアプリ開発者の間でシームレスなデータ交換を促進し、相互運用性と協力を促進します。
