# ルート形状(Shapes) {: #shapes}

## ルート形状(Shapes)データに関するガイダンス {: #shapes-data-guidance}

shapes.txt ファイルに含まれるデータは、交通サービスの表現において重要な役割を果たします。適切に構築されたルート形状(shape)は、経路検索アプリケーションにおける便(trip)の可視化精度を高め、乗客にとってシームレスな体験を保証します。以下の推奨事項は、車両の走行経路を正確に表現し、実際の走行経路と整合する高品質なルート形状データを作成するための指針を示します。

1. 停留所間の走行経路が直線でない場合、2点のみでルート形状を定義することは避けてください。ルート形状が車両の実際の走行経路を正確に反映していることを確認してください。

    <img class="center" width="1500" height="100%" src="../../../../assets/shapes-1.png">

2. ルート形状は始発駅から出発し、終着駅で終了するようにしてください。短すぎる、または長すぎるルート形状は避けてください。

    <img class="center" width="1500" height="100%" src="../../../../assets/shapes-2a.png">

    <img class="center" width="1500" height="100%" src="../../../../assets/shapes-2b.png">

3. 1つの shape_id で定義されるルート形状内で、不自然な折り返しや不要な点の反転を避けてください。

    <img class="center" width="1500" height="100%" src="../../../../assets/shapes-3.png">

4. ルート形状は WGS84 座標系における車両の走行経路と整合していることを確認し、異なる座標系によるずれを避けてください。

    - 道路系サービス（例：バス）の場合、ルート形状は車両が走行する道路の中心線に沿うようにしてください。専用レーンがない場合は道路の中心線に、専用レーンがある場合は走行方向側の中心線に沿うようにします。

        <img class="center" width="1500" height="100%" src="../../../../assets/shapes-4a.png">

    - 鉄道系サービス（例：地下鉄、列車、ライトレール）の場合、ルート形状は列車が走行する線路に沿うようにしてください。特定の区間で列車が常に同じ線路を走行しない場合や複数の線路が存在する場合は、列車が走行する可能性のある線路の範囲内にルート形状が収まるようにしてください。

        <img class="center" width="1500" height="100%" src="../../../../assets/shapes-4b.png">

5. 車両がカーブを走行する場合、乗客に対して視覚的に滑らかに見えるよう、ルート形状の点を十分に密に配置してください。

    <img class="center" width="1500" height="100%" src="../../../../assets/shapes-5.png">

6. ルート形状が縁石停留所、プラットフォーム、または乗車位置に「ジグザグ」するようにずれてはいけません。

    <img class="center" width="1500" height="100%" src="../../../../assets/shapes-6.png">
