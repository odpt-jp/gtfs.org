# MobilityData 推奨事項 {: #mobilitydata-recommendations}


MobilityData は、GTFS の保守を担う非営利団体です。私たちは、交通コミュニティのデータ作成者、利用アプリケーション、オープンデータ愛好家と直接協力し、一連の推奨事項を作成しています。 

これらの推奨事項は、複雑なユースケースに関する質問に答え、一般的に受け入れられている慣行に関する指針を提供し、世界中で作成される GTFS データの全体的な品質を向上させることを目的としています。 

取り上げてほしい主題やトピックがある場合は、Github Discussions でぜひお知らせください。
