# MobilityData の推奨事項 {: #mobilitydata-recommendations}

MobilityData は、GTFS の保守を担当する非営利団体です。私たちは、データ提供者、利用アプリケーション、そして公共交通分野のオープンデータ愛好家と直接協力し、一連の推奨事項を作成しています。

これらの推奨事項は、複雑なユースケースに関する疑問に答え、一般的に受け入れられている実践方法に関する指針を提供し、世界中で作成される GTFS データの全体的な品質を向上させることを目的としています。

取り上げてほしいテーマやトピックがありましたら、ぜひ Github Discussions でお知らせください。
