# [GTFS Digest] 2025年6月 - ガバナンスに投票し、新しいフィールドをチェックしましょう！ {: #gtfs-digest-june-2025-vote-on-governance-and-check-out-a-new-field}


2025年6月のGTFS Digestをお届けします！今月は、新しいGTFSガバナンス構造に関する投票が開始され、締切は2025年7月6日です。ぜひ議論を確認し、投票してください！GTFSコミュニティでは、「cars_allowed」フィールドを追加する提案も可決され、GTFSデータのホスティングに関するベストプラクティスの提案も作成されました。Slackでは多くの新しい会話が始まり、貢献者から素晴らしい回答が寄せられました！

<!-- more -->

GTFS Digestは、[MobilityData](https://mobilitydata.org/)が毎月配信する、GTFSに関する進展の概要を提供するリソースです。

皆様からのフィードバックを大切にしており、新しいレイアウトについてどう思われるかを知りたいと考えています。[このフォーム](https://forms.gle/GGefktvemnJD5Q9g8)にご記入いただき、このツールの可能性を最大限に引き出すためにご協力ください。
