# 車両位置情報(vehicle positions) {: #vehicle-positions}


車両位置情報(vehicle position)は、車載GPSデバイスなどから取得される、車両の位置に関する自動生成情報を提供するために使用されます。これを提供できるすべての車両について、1つの車両位置情報(vehicle position)を提供するべきです。

車両が現在運行している便(trip)は、[TripDescriptor](../../reference/#message-tripdescriptor)を通じて指定するべきです。また、更新情報を提供している対象の正確な物理的車両を指定する[VehicleDescriptor](../../reference/#message-vehicledescriptor)を提供することもできます。ドキュメントは以下に示します。

位置情報の読み取り時刻を示す**timestamp**を提供することができます。これは、サーバーがこのメッセージを生成した時刻であるフィードヘッダー内のtimestampとは異なることに注意してください。

**Current passage**も（`stop_sequence`または`stop_id`として）提供することができます。これは、車両が向かっている、またはすでに停車している停留所等(stop)への参照です。

## 位置情報 {: #position}


Position には、Vehicle Position 内の位置データが含まれます。緯度と経度は必須であり、その他のフィールドは任意です。これらのデータ型は次のとおりです。

*   **緯度** - WGS-84 座標系における北緯（度）
*   **経度** - WGS-84 座標系における東経（度）
*   **方位** - 車両が向いている方向
*   **走行距離計** - 車両が走行した距離
*   **速度** - 車両によって測定された瞬間速度（メートル毎秒）

## CongestionLevel {: #congestionlevel}


車両位置情報(vehicle position)では、事業者が車両が現在経験している混雑レベルを指定することもできます。混雑は、以下のカテゴリに分類できます。

*   不明な混雑レベル
*   円滑に運行中
*   断続的な運行
*   混雑
*   深刻な混雑

各種類の混雑をどのように分類するかは、事業者に委ねられています。私たちのガイダンスでは、深刻な混雑は、交通が非常に混雑して人々が車を降りている状況でのみ使用するべきです。

## OccupancyStatus {: #occupancystatus}


車両位置情報(vehicle position)では、事業者が車両の乗客混雑度を指定することもできます。混雑状況は、以下のカテゴリに分類できます。

*   空席
*   多くの座席が利用可能
*   少数の座席が利用可能
*   立席のみ
*   非常に混雑した立席のみ
*   満員
*   乗客を受け入れていない

このフィールドは依然として**experimental**であり、変更される可能性があります。将来的に正式に採用されることがあります。

## VehicleStopStatus {: #vehiclestopstatus}


車両停留所ステータスは、車両が現在接近中または停車中の停留所等(stop)との関係における車両の状態に、より多くの意味を与えます。以下のいずれかの値に設定できます。

*   **Incoming at** - 車両は参照先の停留所等(stop)にまもなく到着します
*   **Stopped at** - 車両は参照先の停留所等(stop)に停車しています
*   **In transit to** - 参照先の停留所等(stop)は車両の次の停留所等(stop)です - **デフォルト**

## VehicleDescriptor {: #vehicledescriptor}


VehicleDescriptor は正確な物理的車両を記述し、以下の属性のいずれかを含めることができます。

*   **ID** - 車両の内部識別システムです。車両ごとに一意であるべきです
*   **Label** - ユーザーに表示されるラベルです。たとえば列車名です
*   **License plate** - 車両の実際のナンバープレートです
